# Student controls invitation availability

## Outcome

A student marks times they are unavailable so the invitation system stops reaching them then, and the coach is warned before enrolling them into a class that clashes.

- The student's Disponibilidade tab has two cards, each with its own button (PAD-356). Indisponibilidade creates blocks in a sheet (single, or recurring on chosen weekdays between two dates, with an optional reason) and lists them. Pedidos de aula books a class and lists open requests with their state and a withdraw button. A block that ends before it starts is refused.
- A block suppresses automatic invitations for any class overlapping its window.
- A block is meant to suppress every class-slot solicitation (automatic and manual invitations, reminders, waiting-list offers), not automatic invitations alone. Only the automatic half is shipped.
- A coach can still enrol a blocked student by hand after confirming a warning; the student is not told about that addition.
- The coach sees only that a student is unavailable at a time, never the block's title, description or reason.

It does not promise a coach's own personal blocks.
