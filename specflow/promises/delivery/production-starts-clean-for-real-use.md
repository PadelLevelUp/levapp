# Production starts clean for real use

## Outcome

Before real use, production is cleared of the trial's activity: every chat, notification, invitation, waiting list, attendance record and evaluation from the trial goes, and every account, club, class, series roster and student level stays (PAD-632).

- Accounts, clubs, courts, classes, series rosters, upcoming bookings, levels, categories, coach notes, invitations and join links all stay.
- A student's current level never changes; only the record of past level changes is cleared.
- The App Store reviewer's demo coach and student keep everything while the review is open.
- A dry run reports what the clean-up would remove and changes nothing.
- Nothing from the trial is sent again because its history was removed.

It does not promise deleting anything the owner asked to keep, or running the clean-up itself, which the owner's operator does after a backup.
