# Student discovers open spots

## Outcome

A student spots a class they could join inside the calendar they already use, only when their coach advertises it and only for classes they are eligible for, shown distinctly from their own classes.

- Visibility is the coach's toggle and cascades like the bar: coach standard, series, occurrence; most specific wins.
- A private class is not shown to students by default, whatever the standard, unless the coach makes that class or date visible; an academy class follows the standard. This is worked out from the class type, also for existing private classes, and a choice a coach already made is kept (PAD-429).
- A class counts as open only if it really has room, by the calendar's own capacity measure, whether or not the occurrence exists as a record.
- A student sees open spots only for coaches whose roster they are on.
- A student's availability blocks stop them being solicited, never hide a class from their own discovery.
- Looking creates nothing and changes no data.
- Open spots show only in app versions that understand them; older App Store versions show only the student's own classes until updated.
- The difference never rests on colour alone (PAD-578): own classes carry a ✓, an open spot its "Vaga" chip, on web and phone, with a legend. On the student's calendar, colour says what a class is to them: blue for their own, grey for a class with a spot, amber for a full class (waiting list only), with the ✓, outline and a word as the second signal and a legend on every screen size (PAD-664). The coach's calendar keeps the coach's colours.

It does not promise requesting to join, or deciding eligibility.
