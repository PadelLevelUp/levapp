## 1. Regressions (Phase 1 — Playwright) — ❌ ABORTED, RESULTS NOT USABLE

**The regression suite could not be collected this run. Nothing from Phase 1 is filed, and no
pass→fail claim is made.** The cause is environmental and documented, not a product defect.

**What happened.** The Mac is running on **battery** (38%, discharging) and is entering macOS
**Power Nap "Maintenance Sleep"** on a ~950s cycle. From `pmset -g log`, inside the run window:

```
21:02:40  Entering Sleep state due to 'Maintenance Sleep' ... 908 secs
21:17:48  DarkWake ... 2 secs
21:19:07  Entering Sleep state due to 'Maintenance Sleep' ... 927 secs
21:34:34  DarkWake ... 45 secs
21:35:19  Entering Sleep state due to 'Maintenance Sleep' ... 929 secs
21:50:48  DarkWake ... 45 secs
21:51:33  Entering Sleep state due to 'Maintenance Sleep' ... 928 secs
```

The machine was awake roughly **one minute in every sixteen**. Every sleep froze the Flask
webServer, Node and Chromium mid-request. In **65 minutes of wall time only 19 of 288 specs ran**
(a healthy full run is ~6–13 minutes). The 3 failures collected before the abort carry the exact
signature of sleep corruption, not of product bugs:

| Spec | Failure | Signature |
|---|---|---|
| `attendance/attendance-history…::chart range controls` | `locator.fill: Test timeout of 180000ms exceeded` | frozen mid-interaction |
| (login helper) | `apiRequestContext.post: Request context disposed` | context destroyed by sleep |
| `availability/mobile-layout.spec.ts::US-PAD119 blocker form fits the mobile viewport` | `page.waitForURL: Timeout 10000ms exceeded` | frozen mid-navigation |

Per `e2e-battery-powernap-sleep-corruption`, results gathered this way are **non-deterministic
environmental corruption** and must not become tickets. `caffeinate -dis` was **not** attempted —
its `-s` flag is a documented no-op on battery power, and a prior investigation already showed it
makes the run *worse*, not better. The run was killed after one window rather than burning hours.

**Signal that is still valid:** the suite has grown from **188 specs (2026-07-26) to 288** — +100
specs of new coverage landed over the 5-week gap. That count comes from Playwright's own
enumeration at startup, which happens before any sleep, so it is trustworthy.

**Action required (user, one-off):** run the sweep with the Mac **plugged into AC power**, or
disable Power Nap on battery (`sudo pmset -b powernap 0`). Both are outside what an unattended run
may do — the second is a system-settings change. Until then Phase 1 will keep aborting on any
unattended battery run.

**Regression verdict this week: UNKNOWN (not "clean").** The baseline's regression map is carried
forward unchanged rather than overwritten with corrupt data.
