# B-274: locators that climb the page break on harmless markup changes

**Source:** B-282 (2026-10-02). Two E2E tests failed the wave-11 release gate because a helper found a
switch by its text and then climbed `xpath=ancestor::div[contains(@class,'flex')]`; a wrapper that PR
#497 added around the label moved where the climb landed. The product was fine, but the gate was red for
an hour. The rendered-text guard (PAD-320) could not catch it, because the text was still on the page.
Ticket PAD-510.

**What happens:** a locator that climbs from what it found (`xpath=ancestor::…`, `xpath=..`,
`xpath=parent::…`, `locator("..")`) depends on how the markup is nested. Any wrapper, restyle or
layout change can move it, and because Playwright E2E does not run in PR CI, the break is only seen at
the release gate. After the B-282 fix there were 9 climbs in 6 spec files: 7 ancestor climbs and 2
parent climbs.

**Root cause (diagnostic tree):** the E2E conventions had a guard for rendered copy but none for
structural climbing. Type 1, a missing check.

### Change Plan
- **Guard:** `e2e-dom-climb.test.ts` (scanner `e2e-dom-climb-scan.ts`, backlog
  `e2e-dom-climb-backlog.ts`).
  - The same shape as PAD-320: green on landing, each file's count is a ratchet in both directions, and
    the backlog is generated by the guard itself.
  - The scanner is validated before it is trusted.
- **Convert:** each climb becomes a test id or a role, one file at a time.

### Resolution (PAD-510)

- **Guard landed** with 9 climbs across 6 files. All 6 files were then converted, one commit each, and
  the backlog is now empty.
- **Test ids added:** `exercise-card-<id>`, `message-bubble-<id>`,
  `restriction-row-cancellation-deadline`, `class-detail-capacity`, `invitation-group-<index>`.
- **Existing ids reused:** `reminder-per-student`, `standing-wl-entry`.
- **Verification:** each converted spec passed on an isolated Playwright stack.
- **Maestro:** has no xpath. Its relative selectors (`below:` 5, `above:` 1, `rightOf:` 2) are a
  layout dependency of a related kind, left for a later, separate ratchet.
